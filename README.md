# Biodiversity Data Analysis

## Objective
Explore biodiversity open data to understand species distribution and identify potential environmental patterns.

## Data
Data will be sourced from open biodiversity databases (e.g. GBIF, INPN).

## Method
- Data cleaning
- Exploratory data analysis
- Statistical analysis
- Visualization

## Results
Results will include graphs and potentially spatial visualizations.

## Conclusion
This project aims to demonstrate how ecological data can be analyzed to extract meaningful insights.

## Tools
- R / Python
- QGIS (if spatial analysis)
